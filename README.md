# Небесный патруль — Telegram Mini App на React + PixiJS

Аркада: самолётик летит за пальцем, стреляет автоматически и сбивает пришельцев.

- 3 вида врагов: зелёные разведчики (быстрые, летают клином), летающие тарелки (качаются и стреляют), корабль-матка (босс с полоской здоровья)
- Бонусы: ★ усиливает пушку (до 3 уровней), ♥ даёт жизнь (до 5)
- Сложность растёт со временем
- Рекорд хранится в localStorage и в облаке Telegram (CloudStorage), то есть синхронизируется между устройствами
- Вибрация через Telegram HapticFeedback, системная кнопка «Назад» ставит игру на паузу, свайп вниз не закрывает приложение посреди боя
- Работает и в обычном браузере (мышь, стрелки/WASD, Esc — пауза)

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (и по IP в локальной сети — можно открыть с телефона)
npm run build      # production-сборка в dist/
```

`npm run build:single` собирает всю игру в один `dist-single/index.html` (без скрипта Telegram) — удобно для быстрого превью.

## Структура

```
src/
  App.tsx            React: экраны (меню, пауза, game over), HUD, связь с Telegram
  telegram.ts        обёртка над Telegram WebApp API (безопасна вне Telegram)
  game/
    Game.tsx         мост React ↔ Pixi: создаёт мир, передаёт тики (useTick) и ввод
    World.ts         вся игровая логика: игрок, враги, пули, бонусы, столкновения
    textures.ts      векторная графика, запекается в текстуры при старте
```

Почему логика в обычном классе, а не в React-компонентах: на экране сотни объектов, которые меняются 60 раз в секунду. Через state React это было бы медленно, поэтому мир обновляет спрайты напрямую, а в React уходят только редкие события (очки, жизни, конец игры).

Чтобы заменить графику на свои картинки, загрузите их через `Assets.load()` из `pixi.js` и подставьте в `textures.ts`.

## Как подключить к Telegram

1. **Опубликуйте сборку по HTTPS.** Telegram открывает только https-адреса. Самое простое:
   - Vercel / Netlify: импортируйте репозиторий, команда сборки `npm run build`, папка `dist`;
   - или GitHub Pages: загрузите содержимое `dist/` (в конфиге уже стоит `base: './'`).
2. **Создайте бота** в [@BotFather](https://t.me/BotFather): `/newbot`.
3. **Привяжите Mini App** — любой из способов:
   - `/newapp` → выберите бота → укажите URL. Получите ссылку вида `t.me/<бот>/<имя_приложения>`;
   - или `/mybots` → бот → *Bot Settings* → *Configure Mini App* (или *Menu Button*) → укажите URL. Кнопка запуска появится в чате с ботом.
4. Откройте бота в Telegram и нажмите кнопку — игра запустится.

### Отладка на телефоне во время разработки

Запустите `npm run dev` и пробросьте порт наружу по https, например:

```bash
npx cloudflared tunnel --url http://localhost:5173
# или: ngrok http 5173
```

Полученный https-адрес временно укажите в BotFather как URL приложения. Если Vite ругается на чужой хост, добавьте его в `server.allowedHosts` в `vite.config.ts`.

## Идеи для развития

- Таблица лидеров между друзьями (нужен свой бэкенд, проверка `initData` на сервере)
- Звуки и музыка (`@pixi/sound`)
- Разные самолёты и магазин улучшений
- Кнопка «Поделиться результатом» через `shareMessage` / `switchInlineQuery`
