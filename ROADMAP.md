# Небесный патруль: план развития

Аркада в Telegram Mini App: самолёт сбивает пришельцев.
Стек: React + PixiJS (@pixi/react), Vite, GitHub Pages.

**Цель:** короткие сессии по 1–3 минуты, к которым хочется возвращаться.
Каждая версия должна оставлять игру рабочей и готовой к выкладке.

Обозначения: `[x]` сделано, `[ ]` в планах.
Размер задачи: **S** — вечер, **M** — 2–3 вечера, **L** — неделя и больше.

## Как вести этот план

1. Каждый пункт текущей версии заводится задачей в **GitHub Issues** с ярлыком (`фича`, `баг`, `баланс`, `тех`).
2. Версии оформлены как **Milestones** (`v0.2`, `v0.3`…).
3. В коммите пиши `fix #N` — задача закроется сама после push.
4. Когда версия готова — отметь пункты здесь `[x]`, поставь git-тег (`git tag v0.2 && git push --tags`).
5. Новые идеи сначала в раздел «Идеи на потом», в план — только после обдумывания.
